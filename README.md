# Human Technologies

Website for **Human Technologies**, a digital transformation company focused on the manufacturing industry.

## About

Human Technologies helps manufacturing companies transform the way they use operational data, technology and processes to make better decisions.

The approach combines:

- Digital transformation for manufacturing
- Real-time production data
- Automatic data capture
- Operational visibility
- Preventive maintenance
- Financial impact analysis
- Team capability development
- Diagnosis, pilot and scalable implementation

### Our approach

> **La tecnología hace el trabajo. Su gente hace lo importante.**

The objective is not simply to introduce more technology into the plant. It is to give people better information and tools so they can use their experience to analyze, improve and make better decisions.

## Website

This repository contains the static website for Human Technologies.

The current website is built as a lightweight static HTML site, with CSS and JavaScript integrated directly into the page.
